# Personal_Website

Personal portfolio site built with Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` – development server
- `npm run build` – production build
- `npm run start` – run production build
- `npm run lint` – ESLint
